# Beck Holiday Homes

Scaffolded React app using Vite.

Quick start (PowerShell):

```powershell
cd "c:\Users\techg\OneDrive\Desktop\Beck_Holiday_homes"
npm install
npm run dev
```

Build for production:

```powershell
npm run build
npm run preview
```

Files of interest:
- `index.html` — app entry
- `src/main.jsx` — React bootstrap
- `src/App.jsx` — main app component
